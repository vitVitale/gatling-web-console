About Gatling Web Console

Gatling Web Console is a web-based interface for running and analyzing Gatling performance tests. It provides a simple way to execute tests and view results without having to use the command line.

This is a clone of Gatling Enterprise Frontline, providing similar functionality in a simplified form.
